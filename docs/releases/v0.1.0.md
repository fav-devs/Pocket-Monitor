# Pocket Monitor 0.1.0 — Windows preview

This is the first packaged Windows preview of Pocket Monitor: a laptop viewfinder and control
surface for DJI Osmo Pocket cameras.

## Highlights

- Direct live view with record, still, zoom, gimbal, tracking, format, and exposure controls.
- Monitoring tools including zebra, peaking, LUT preview, waveform, guides, grids, and audio meters.
- Camera settings, media browsing and playback, controller input, and virtual-camera output.
- Saved Windows Wi-Fi reconnect after the initial camera pairing flow.

## Download

- **Installer:** `OpenPocketCine-Setup-0.1.0.exe`
- **Portable:** `OpenPocketCine-0.1.0-windows-x64.zip`
- **Integrity:** verify either download with `SHA256SUMS.txt`.

The installer can register the optional Windows virtual camera and therefore requests
administrator access. The portable ZIP does not install anything; extract it and run
`opc-monitor.exe`.

## Preview caveats

- The binaries are not Authenticode-signed, so Windows may show a SmartScreen warning.
- Direct-camera behavior is still being hardened across firmware, Wi-Fi adapters, and GPU drivers.
- Confirm record state on the camera body until this preview is proven with your setup.
- Keep `opc-monitor.log` when reporting a feed or reconnect problem.
