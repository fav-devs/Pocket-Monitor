# FFmpeg provenance for OpenPocketCine 0.1.0

The Windows 0.1.0 binaries dynamically link to the unmodified FFmpeg DLLs from the BtbN
`win64-lgpl-shared-8.1` build published on 2026-09-24.

- FFmpeg version: `n8.1.3-20260924`
- Binary asset: `ffmpeg-n8.1-latest-win64-lgpl-shared-8.1.zip`
- Binary SHA-256: `a188eb393f156c31f4ec9a9d978573645d996bc7ed219b30a48e0edf128f9c62`
- BtbN build-scripts commit: `20ad148c3b69a862b061eb7e6cc7b61d896bcfef`
- FFmpeg source tag: `n8.1.3`
- Configuration: shared libraries, `--enable-version3`, without `--enable-gpl` or
  `--enable-nonfree`

The same GitHub Release includes `ffmpeg-n8.1.3-source.zip` and
`ffmpeg-build-scripts-20ad148-source.zip`. The complete configure line is available from
`ffmpeg.exe -buildconf` in the pinned upstream binary archive. `FFmpeg-LICENSE.txt` is included
inside both OpenPocketCine Windows packages.
