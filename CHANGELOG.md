# Changelog

All notable changes to Pocket Monitor are recorded here. The project follows Semantic
Versioning while the desktop application is in active validation.

## [Unreleased]

## [0.1.0] - 2026-09-24

### Added

- Windows desktop viewfinder with direct Pocket camera connection and saved Wi-Fi reconnect.
- Recording, still, zoom, gimbal, tracking, exposure, format, and camera-setting controls.
- Monitoring assists, scopes, media library and playback, game-controller input, and virtual-camera output.
- Windows installer and portable ZIP release packages with SHA-256 checksums.

### Known limitations

- Windows binaries are unsigned and may trigger a SmartScreen warning.
- Camera, firmware, GPU, and long-session coverage remains in active physical validation.
- Firmware updates, activation, and DJI account features remain in DJI Mimo.
